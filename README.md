# Training Tracker (筋トレ＆PFC・コンディション管理)

日々のトレーニング記録と栄養（PFC）・コンディション（睡眠時間・トレ前糖質）を連携させ、
推定1RMや相関を可視化するスマートフィットネス PWA アプリです。

- **プライバシー保護 & サーバーレス:** データは端末内（ブラウザの localStorage）にのみ保存され、外部に送信されません。
- **インストール不要:** URL を開いて「ホーム画面に追加」することで、ネイティブアプリ感覚で全画面起動できます。
- **バンドラレス長寿命設計:** HTML / Vanilla CSS / ES Modules で構築され、ビルド工程・外部 npm 依存パッケージ不要。

---

## 主な機能

1. **🏋️ ワークアウト記録**
   - 種目選択時の前回重量・回数の自動プレースホルダー反映
   - セット種別フラグ（`UP` 準備 / `MAIN` 基本 / `HEAVY` MAX / `DOWN` 調整）
   - 重量と回数からのリアルタイム推定1RM算出（Epley式）
   - セッション総ボリューム（重量 × 回数）の自動集計
   - トレ前コンディション（睡眠時間チップ、トレ前糖質補給有無、体調5段階、体重）
2. **⏱ スマートインターバルタイマー**
   - セット種別に応じた既定時間サジェスト（UP 60s, MAIN 120s, HEAVY 180s）
   - タブ移動中も常駐するフローティングミニバー ＆ 拡大ダイヤルモーダル
   - Web Audio API による終了音・カウントダウン音響通知
3. **🥗 PFC＆栄養管理（引き算・クイック入力）**
   - 目的（減量 / 維持 / 増量）に応じた目標カロリー・目標PFCの自動算出（Mifflin-St Jeor式）
   - クイック数値直接入力（P / F / C）
   - マイルーティン（「いつものプロテイン」「トレ前バナナ」等）のワンタップ加算
   - 必須サプリメント（クレアチン、マルチビタミン等）のデイリーチェックリスト
4. **📊 分析・相関ダッシュボード**
   - 体重推移 vs 指定種目の推定1RM オーバーレイチャート（Canvas描画）
   - 睡眠不足時の出力低下やトレ前糖質の恩恵を提示するインサイトアラート
   - 漸進性過負荷（オーバーロード）サジェスト（前回完遂時の次回+2.5kg提案）
5. **⚙️ 設定＆バックアップ**
   - ユーザープロファイル・目標体重・活動レベル設定
   - マイルーティン・サプリメント項目の自由なカスタマイズ
   - ワンクリック JSON エクスポート / インポート（端末間引き継ぎ用）

## ホーム画面への追加方法（PWA）

### iPhone / iPad（Safari）
1. Safari で本アプリの URL を開く
2. 画面下部（iPad は上部）の共有ボタン（`□↑`）をタップ
3. **「ホーム画面に追加」** ➔ **「追加」**

> ⚠️ **iOS Safari の注意:** ブラウザタブのまま長期間放置するとストレージが消去される場合があります。必ず「ホーム画面に追加」して PWA として起動してください。

### Android（Chrome）
1. Chrome で本アプリの URL を開く
2. メニュー（`︙`）➔ **「ホーム画面に追加」** または **「アプリをインストール」**
